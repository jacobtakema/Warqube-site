# Getting Started

This section will help you get Warqube up and running for the first time.

<figure>
  <img src="/assets/images/loading/load.png" alt="Warqube Load Content page">
</figure>

Start by downloading Warqube and follow the installation instructions to set up the required components. Once installation is complete, the **First Start** guide will take you through launching Warqube and preparing your first analysis.

After completing these steps, continue with the [User Guide](../UserGuide/userguide.html) to explore Warqube's analysis and exploration features.
