# Download

Warqube v1.0.0 is the first public release. The source code is available from
the [Warqube repository on GitHub](https://github.com/jacobtakema/Warqube).

Download the v1.0.0 source archive from [GitHub Releases](https://github.com/jacobtakema/Warqube/releases)
and extract it to a directory where you have permission to create files. Keep
the directory structure intact.

Warqube currently supports Windows. Before installing it, make sure that R
4.4.0 or later and Java are available from the command line. Continue with the
[installation instructions](installation.html) for the complete prerequisites
and installer steps.
